# 🌸 Mini Frontend Projects

This repository contains multiple frontend projects built using HTML, CSS, and JavaScript.  
These projects helped me strengthen my core frontend development skills.

---

## 📸 Photography Website

**Technologies Used:** HTML, CSS  

A simple static photography website built using only HTML and CSS.  
The focus of this project was to practice layout design and styling.

### Features:
- Clean and structured layout
- Custom CSS styling
- Image sections
- Static design (non-interactive)

---

## 🎵 Spotify Clone (Frontend Only)

**Technologies Used:** HTML, CSS  

A frontend UI clone of the Spotify web player.  
This project recreates the design and layout of Spotify.

### Features:
- Sidebar navigation
- Music player layout
- Custom icons and images
- Frontend design only (Not responsive)

---

## 🎮 Simon Game

**Technologies Used:** HTML, CSS, JavaScript  

A functional memory-based color game inspired by the classic Simon game.  
This project focuses on JavaScript logic and DOM manipulation.

### Features:
- Random color sequence generation
- User click tracking
- Level progression system
- Game over detection
- Keyboard key to start the game
- Button flash animations
